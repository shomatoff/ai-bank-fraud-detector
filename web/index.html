Methodology

  1. Generate transactions and stochastic labels with a fixed seed.
  2. Split development chronologically: 60% fit, 20% calibration, 20% validation; use a later test seed.
  3. Select model and threshold on validation, then evaluate on the later test.
  4. Report ROC AUC, PR AUC, precision, recall, F1, and Brier score.
